# Urban Dukaan

Urban-Dukaan is a fully-fledged front-end E-commerce website built using HTML, CSS, JavaScript, and Bootstrap, designed to provide a beautiful and responsive shopping experience. This project includes various functionalities such as theme changer, carting, and checkouts.

## Features

- **Responsive Design:** Optimized for all device sizes using Tailwind CSS and Bootstrap.
- **Theme Changer:** Switch between different themes.
- **Cart Functionality:** Add items to the cart, view cart items, and proceed to checkout.
- **Beautiful UI:** Modern and visually appealing design.
- **Modular Code:** Clean and maintainable code focusing on reusability.

## Installation

To get a local copy up and running, follow these simple steps:

1. **Clone the repository:**

    ```bash
    git clone https://github.com/AmazingAshish/Urban-Dukaan.git
    ```

2. **Navigate to the project directory:**

    ```bash
    cd Urban-Dukaan
    ```

3. **Install the dependencies:**

    Ensure you have `npm` installed. Then, run:

    ```bash
    npm install
    ```

4. **Start the development server:**

    ```bash
    npm run dev
    ```

    This will start the Tailwind CSS watcher.

## Usage

Open your browser's `index.html` file to view the website locally. You can also navigate through the different pages like `shop.html`, `cart.html`, `sproduct.html`, etc.
